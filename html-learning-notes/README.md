## 🛠️ Kaise Chalaye Code?

1. Koi bhi `.html` file pe double-click karo — browser me khul jayegi.
2. Code dekhne ke liye VS Code me kholo.
3. Change karke save karo → Browser me Refresh karo.

> **VS Code Extension:** Live Server install kar lo. Right Click → Open with Live Server. Save karte hi browser khud refresh hoga.
