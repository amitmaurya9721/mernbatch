# JavaScript Study Notes – Basic to Advanced

Beginner-friendly JavaScript revision notes for MERN Stack learning.

## Folder Structure
- `01-Fundamentals/` – Introduction, variables, data types
- `02-Core-JavaScript/` – Operators, conditions, loops
- `03-Functions-and-Scope/` – Functions, scope, hoisting, closures
- `04-Arrays-and-Objects/` – Arrays, array methods, objects
- `05-ES6-and-Advanced/` – ES6+, this, execution context, call stack, event loop
- `06-DOM-and-Events/` – DOM, events, bubbling, delegation
- `07-Async-JavaScript/` – Callbacks, promises, async/await, Fetch, JSON, errors
- `08-MERN-JavaScript/` – JavaScript concepts used in React, Node and Express
- `Interview-Questions/` – Common interview questions and short answers
- `Coding-Practice/` – Hands-on coding problems

## How to Study
1. Read one file at a time.
2. Type every code example yourself.
3. Run examples in browser console or Node.js.
4. Solve the practice questions without looking at solutions.
5. Revise interview questions aloud.

**Note:** Examples are intentionally short. Use official documentation for deeper reference.
